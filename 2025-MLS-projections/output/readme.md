# **2025-MLS-projections/output**

### **Purpose**

> The output folder stores the results of running rebuilding projections under CMM 2024-06 for WCNPO striped marlin

### **Folder Structure**

> -   **Base Runs** contains the AGEPRO projection output for the rebuilding scenarios under CMM 2024-06.
> -   **Presentations** contains several historic and draft presentations for the WCNPO striped marlin projections.
> -   **Sensitivity Runs** contains output information from projection sensitivity analyses using alternative input data for CMM 2024-06.
