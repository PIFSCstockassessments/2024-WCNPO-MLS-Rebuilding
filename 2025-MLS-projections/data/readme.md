# **2025-MLS-projections/data**

### **Purpose**

> The "data" folder stores catch data, population abundance data, CMM 2024-06 information, fleet information, and rebuilding scenario information for running rebuilding projections under CMM 2024-06 for WCNPO striped marlin

### **Folder Structure**

> -   **2020 Year Class** contains information on the 2020 year class and the initial population abundances used for the rebuilding scenarios under CMM 2024-06.
> -   **BSIA Catch** contains the best scientific information available for WCNPO striped marlin catch.
> -   **CMM 2024-06 Scenarios** contains information on the rebuilding scenarios for CMM 2024-06.
> -   **Fleet Groups** contains information about the fleets and fleet groups used in the 2023 stock assessment and the rebuilding scenarios for CMM 2024-06.
> -   **Japanese Catch** contains the information on Japanese catch of striped marlin by fleet.
> -   **References** contains relevant references for the rebuilding analyses.
> -   **US Catch** contains the information on United States catch of striped marlin by fleet.
> -   **WCPFC Tuna Fishery Yearbook Catch** contains the catch information from the WCPFC 2024 Tuna Fishery Yearbook.
> -   **WCPFC21** contains information on the 21st WCPFC Commission Meeting and CMM 2024-06 text.
